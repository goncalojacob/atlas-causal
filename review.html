This page is a tool for maintainers. The map does not link to it. It exists to end one rule: the dated exception in CLAUDE.md that let an assistant draft records, so the interface could be built and tried on real material. A record that nobody has read has review.status set to draft until somebody signs it. The queue on the left lists exactly those records, whoever wrote them. A contribution or an import that arrives unread is in it too. When you read a record, correct what is wrong and sign it, the page adds your name to the record, and your name and the date to review.signedBy.

Saving needs the local server. Run node tools/serve.mjs and open this page at http://localhost:8000/review.html. There, each save first checks the record against the whole atlas. Then the server rewrites the record file and rebuilds data/index/. Neither python3 -m http.server nor the published site can write files. Opened any other way, the page puts each save on your clipboard as a correction bundle and opens the correction issue. Nothing is lost either way, and the public site needs no server of its own.

The queue is one list that you can sort four ways. flags puts first the records that the validator or the drafter flagged for a look. degree puts first the records with the most links to the rest of the atlas. oldest puts first the records that have waited longest. kind follows the order of the contribution form. The chips under the list filter it by kind, by flag and by the writer who made the record. The list is as long as the queue, but the page only builds the rows on screen.

Claim a record if somebody else might be reading it too. A claim puts your name and the date in review.claimedBy. The list shows it, and it expires after a week. A claim does not stop anyone else from saving. Signing the record removes it. Beside the record, the page shows its history from the repository's commits. Once you change anything, it also shows what you changed since the draft.

Keys: j and k (or the arrow keys) move through the queue. ctrl+s saves. ctrl+enter signs.
