The twelve symbols

One per category of data/categories.json, drawn by src/map/glyphs.js — this page holds no copy of them, it asks the module. Each row is the same drawing at ten pixels (the size it is on a mark), at the layer control's row size, and large enough to see the line work; then on a plain mark and on an emphasised one, which are the two grounds it has to read on.

This is the contact sheet owner question 11 reserves: which twelve shapes, and which to redraw. Redrawing one is one <symbol> and no test. tools/screens.mjs photographs this page as docs/screens/glyphs-legend.png.
